# Small Website Design Refresh

I've made some minor visual design changes to most of the website in an attempt to make it a bit more visually pleasing and more consistent. 

The main new feature here is the use of `corner-shape: squircle` for the rounded corners of most elements. Using corner-shape makes everything look smoother and everything looks more modern. Pretty much every page (except for the art portfolio) makes use of the corner-shape element. In the future everything else will be updated as well to make sure the website pages are consistent with each other.

I also introduced some new highlight animations for the navbar, buttons and other elements, inspired by Fortnite's Lobby/Locker UI design.

Besides that, I focused on improving some animations in the art portfolio. These changes are minor, but I feel like it makes the portfolio itself more playful and less static.

## List of all changes:
- Rounded corners are now squircles [Chromium only]
- Improved highlight animations for navbar, elements and buttons.
- Added "expand" animation for the art portfolio.
- Page(s) for game projects (and maybe a blog?)
